DSA Technical Highlights
  • • BST Dictionary Storage: Inorder traversal yields lexicographically sorted words; search, insertion, and deletion operate in O(h) time.
  • • Smart Suggestions: Powered by Levenshtein distance metric (insertions, deletions, substitutions) bounded by edit distance ≤ 2.
  • • BST Deletion: Properly handles 3 cases: leaf node removal, single child replacement, and two-children node replacement with inorder successor.
